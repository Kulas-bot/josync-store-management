# JoSync

Offline-First Sari-Sari Store Management App

## 📱 About

JoSync is a mobile application designed to help sari-sari
store owners manage their daily store operations without
requiring an internet connection.

## 🎯 Problem

Traditional paper-based inventory and ledger tracking can
make it difficult to monitor products, sales, and customer
debts.

## ✨ Features

- Inventory Management
- High / Low / Out of Stock tracking
- Daily Sales
- Borrower Ledger
- Borrowed Items
- Payment Tracking
- Shopping List
- Dashboard
- Reports
- Offline SQLite Storage

## 🛠️ Tech Stack

- React Native
- Expo
- TypeScript
- Expo SQLite
- Git / GitHub

## 🏗️ Architecture

UI
↓
Business Logic / Services
↓
Repositories
↓
SQLite
